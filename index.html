                      House rules for the code

                      • Arrays are the database

                        Applications, subscribers, bills, payments, tickets and staff are plain arrays kept in memory. The site is a single page, so nothing has to be transferred between pages.

                      • Procedural, not object-oriented

                        Only functions and plain records — no classes, no this, no methods on data.

                      • No built-in helpers for data

                        Never used: push, pop, shift, unshift, splice, slice, sort, reverse, indexOf, includes, find, filter, map, forEach, reduce, join, split, replace, trim, toLowerCase or regular expressions. Hand-written versions live in assets/js/dsa/.
